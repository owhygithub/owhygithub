## What I work on

I like problems where the data has structure that a flat model throws away. Transactions form graphs. Stocks influence each other. Contracts have clauses that reference other clauses. Most of my work is about finding that structure and building something that uses it.

At work that means LLM extraction over legal documents, RAG systems, and booking-curve forecasting. Twelve client projects so far across pricing, retail, travel and manufacturing, from first prototype through to delivery.

Outside work I ship small products under the **Anoda** name, mostly to learn things I cannot learn in a client project.

## Selected work

**[TAGC: Stock Ranking with a Learned Graph](https://github.com/owhygithub/prj-1-TAGC-StockRanking-GNN-2026)**
`PyTorch` `GNN` `Transformers` `Quant`
MSc thesis. A transformer encoder feeds a Temporal Attention Graph Constructor that learns inter-stock relationships dynamically instead of assuming a fixed correlation structure, then ranks S&P 500 returns cross-sectionally. The interesting result was negative across multiple seeds, and the write-up treats it that way.

**[AML Fraud Detection with Temporal GNNs](https://github.com/owhygithub/prj-1-AMLFraudDetectionModel-DeepLearning-GNN-2024)**
`PyTorch` `Temporal GNN` `Fraud`
BSc thesis. Modelling how laundering patterns move through a transaction network over time rather than scoring each transaction in isolation. Shaped by four years of watching real fraud at Adyen.

**[oskarwang.com](https://github.com/owhygithub/prj-1-PhotographyWebsite-software-2025)**
`JavaScript` `GitHub Pages`
Portfolio site for my photography practice. 210 photographs, no framework, no bundler, no runtime dependencies. Thirty releases and counting.

## How this profile is organised

Repos follow a naming convention so the list stays readable at forty and beyond.

| Prefix | Meaning |
|---|---|
| `prj-1-` | Projects and products I built, public or private. Classified by scale, so the two theses live here too |
| `prj-0-` | Internal tools and one-offs |
| `uni-` | Coursework, grouped by degree and year |
| `course-` | Bootcamps and self-study notebooks |
| `archive-` | Retired, kept for reference |

Format after the prefix is `Name-TechTags-Year`, so `prj-1-AMLFraudDetectionModel-DeepLearning-GNN-2024` tells you everything before you click.
